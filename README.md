# StudySync Hub

A polished, production-ready full-stack web application called **StudySync** — a shared productivity and learning-progress tracker for students.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
